## 矩阵乘法平铺

（Loop Tiling / Blocked Matrix Multiplication）是一种通过将大矩阵划分为小数据块（Tile），以提高计算机缓存（Cache）命中率并优化访存性能的算法。

平铺矩阵乘法核心思想

1. 将 \(N \times N\) 矩阵划分为大小为 \(B \times B\) 的小方块。
2. 每次把一个或多个小方块加载到快速缓存（SRAM/Cache）中进行重复计算。
3. 减少从慢速主存（DRAM）反复读取数据的次数。

矩阵乘法平铺伪代码

```
// 假设矩阵大小为 N x N，分块大小为 B
// C 初始化为 0
for i_block = 0 to N-1 step B
    for j_block = 0 to N-1 step B
        for k_block = 0 to N-1 step B
            
            // 对当前小方块 (Block) 进行标准的内积计算
            for i = i_block to min(i_block + B - 1, N - 1)
                for j = j_block to min(j_block + B - 1, N - 1)
                    sum = 0
                    for k = k_block to min(k_block + B - 1, N - 1)
                        sum = sum + A[i][k] * B[k][j]
                    end for
                    C[i][j] = C[i][j] + sum
                end for
            end for
            
        end for
    end for
end for
```
