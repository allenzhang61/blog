线性回归代码示例

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# 1. 准备数据
# 生成一些随机数据作为示例
# 该示例是一个y=a+bx形式的例子，其中a大约是4，b大约是3
np.random.seed(0)
X = 2 * np.random.rand(100, 1)  # 生成 100 个 0 到 2 之间的特征值
y = 4 + 3 * X + np.random.randn(100, 1)  # 目标值 y = 4 + 3x + 噪声

# 2. 创建并训练模型
model = LinearRegression()
model.fit(X, y)  # 训练模型，寻找最佳拟合线
# 输出拟合出来的a值和b值
print(f"截距a (Intercept): {model.intercept_[0]:.2f}")
print(f"斜率b (Coefficient): {model.coef_[0][0]:.2f}")

# 3. 进行预测
X_new = np.array([[0], [2]])  # 测试两个点：x=0 和 x=2
y_predict = model.predict(X_new)

# 4. 评估模型
y_pred_all = model.predict(X)
print(f"均方误差 (MSE): {mean_squared_error(y, y_pred_all):.2f}")
print(f"拟合优度 (R²): {r2_score(y, y_pred_all):.2f}")

# 5. 可视化结果
plt.scatter(X, y, color='blue', label='Data Points')  # 原始数据散点图
plt.plot(X_new, y_predict, color='red', linewidth=2, label='Regression Line')  # 拟合线
plt.plot(X_new, y_predict, color='red', marker='o', linestyle='None', markersize=8)
plt.xlabel('X (Feature)')
plt.ylabel('y (Target)')
plt.title('Linear Regression Example')
plt.legend()
plt.show()
```

## 指标公式说明

### MSE（均方误差）
- 定义：度量预测值与真实值的平均平方偏差，越小越好。
- 公式（LaTeX）：
  $$\mathrm{MSE} = \frac{1}{n} \sum_{i=1}^{n} \left(y_i - \hat{y}_i\right)^2$$
- 术语说明：$n$ 为样本数量；$y_i$ 为真实值；$\hat{y}_i$ 为模型预测值。

### R²（拟合优度）
- 定义：衡量模型对因变量方差的解释比例，越接近 1 表示拟合越好。
- 公式（LaTeX）：
  $$R^2 = 1 - \frac{\sum_{i=1}^{n} \left(y_i - \hat{y}_i\right)^2}{\sum_{i=1}^{n} \left(y_i - \bar{y}\right)^2}$$
- 术语说明：$\bar{y}$ 为 $y$ 的样本均值；分子为残差平方和（SS_res）；分母为总平方和（SS_tot）。
- 说明：包含截距的线性回归中通常 0 ≤ R² ≤ 1；无截距模型可能出现负值。
