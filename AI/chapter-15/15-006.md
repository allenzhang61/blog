# 静态共享内存 vs 动态共享内存

CUDA 里的共享内存（shared memory）是 block 内线程共享的一块高速缓存。按大小确定的时机，可以分成静态共享内存和动态共享内存。

## 静态共享内存

静态共享内存的大小在编译期确定：

```cpp
__shared__ float tile[32][32];
```

这种写法适合大小固定、结构清楚的场景，比如矩阵乘法里固定使用 `32 x 32` 的 tile。优点是代码直观，可以写成二维数组，编译器也更容易利用常量大小做优化。

## 动态共享内存

动态共享内存的大小在 kernel 启动时指定：

```cpp
extern __shared__ float smem[];

kernel<<<grid, block, shared_bytes>>>(...);
```

这种写法适合 shared memory 大小需要根据输入、block size 或运行参数变化的场景。缺点是通常要自己切分内存区域，例如把同一块 `smem` 分成 `tileA` 和 `tileB`。

## 怎么选

| 场景 | 建议 |
| --- | --- |
| tile 大小固定 | 用静态共享内存 |
| 想写清楚的二维数组访问 | 用静态共享内存 |
| block size 或缓存大小运行时才知道 | 用动态共享内存 |
| 一个 kernel 里要灵活切多块缓存 | 用动态共享内存 |

简单说：固定形状优先静态，运行时变化优先动态。两者都使用同一类硬件 shared memory，区别主要在大小确定方式和代码组织方式。
