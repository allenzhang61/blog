## hello world

![](/static/images/2607/p001.png)

```
#include <stdio.h>

__global__ void helloFromGPU(void){
  printf("hello\n");
}

int main(void){
  helloFromGPU<<<1, 10>>>();
  cudaDeviceReset();
  return 0;
}
```

`cudaDeviceReset();` 这行代码如果被注释掉，hello就不再输出了。原因是GPU Kernel 的执行是异步（Asynchronous）的，注释掉，程序很可能直接结束，所以 GPU 还没来得及执行 printf，进程就退出了。

cudaDeviceReset不仅仅是”重置GPU”。它内部会：

1. 等待所有 Kernel 完成（Synchronize）
2. Flush printf buffer
3. 清理 CUDA Context

更多的是使用cudaDeviceSynchronize，不做cuda context的清理。
