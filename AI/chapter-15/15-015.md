表 6.1 优化清单
1. 最大化占用率（Maximizing occupancy）
- 对计算核心的收益： 提供更多可执行工作以隐藏流水线延迟。
- 对内存系统的收益： 产生更多并行内存访问以隐藏 DRAM 延迟。
- 策略： 调节流式多处理器（SM）资源的使用，如每个块的线程数、每个块的共享内存大小以及每个线程的寄存器数量。
2. 实现全局内存合并访问（Enabling coalesced global memory accesses）
- 对计算核心的收益： 减少因等待全局内存访问而导致的流水线停顿。
- 对内存系统的收益： 降低全局内存数据流量，提高突发传输（Burst）与缓存行（Cache line）的利用率。
- 策略： 
    - 以合并方式在全局内存与共享内存之间传输数据，而在共享内存中执行非合并访问（例如转置 / corner turning）。 
    - 重新排列线程到数据的映射关系。 
    - 重新排列数据的内存布局。
3. 最小化控制发散（Minimizing control divergence）
- 对计算核心的收益： 提高 SIMD 效率（减少 SIMD 执行期间闲置的核心数量）。
- 对内存系统的收益： 无（—）。
- 策略： 
    - 重新排列线程到工作任务和/或数据的映射关系。 
    - 重新排列数据的内存布局。
4. 复用数据分块（Tiling of reused data）
- 对计算核心的收益： 减少因等待全局内存访问而导致的流水线停顿。
- 对内存系统的收益： 降低全局内存数据流量。
- 策略： 将线程块内重复使用的数据放置在共享内存或寄存器中，使这部分数据在全局内存与 SM 之间仅传输一次。
5. 私有化（Privatization，后续章节介绍）
- 对计算核心的收益： 减少因等待原子更新（Atomic updates）而导致的流水线停顿。
- 对内存系统的收益： 减少原子更新引起的资源争用与串行化。
- 策略： 先对数据的私有副本执行局部更新，完成后再一次性更新全局公共副本。
6. 线程粗粒度化（Thread coarsening）
- 对计算核心的收益： 减少冗余计算工作、控制发散或同步开销。
- 对内存系统的收益： 减少冗余的全局内存流量。
- 策略： 当并行化带来不必要的额外开销时，为每个线程分配多个并行处理单元，以降低并行化的代价。
