```
class MyNeuralNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.input_to_hidden_layer = nn.Linear(2,8)
        self.hidden_layer_activation = nn.ReLU()
        self.hidden_to_output_layer = nn.Linear(8,1)

    def forward(self, x):
        x = x@self.input_to_hidden_layer
        x = self.hidden_layer_activation(x)
        x = x@self.hidden_to_output_layer
        return x
```

定义损失函数：

```
loss_func = nn.MSELoss()
```

计算损失：

```
_Y = mynet(X)
loss_value = loss_func(_Y, Y)
print(loss_value)
```

```
opt = SGD(mynet.parameters(), lr=0.001)
```

```
# 更新权重后，确保在下一个训练周期中计算梯度之前，清空上一步计算得到的梯度
opt.zero_grad()
# 计算给定输入和输出对应的损失值
loss_value = loss_func(mynet(X), Y)
# 计算每个参数对应的梯度，把梯度保存到每个 parameter 的.grad 属性中
loss_value.backward()
# 根据学习率以及每个参数的梯度，更新参数值
opt.step()
```

执行 50 个训练周期的选中更新，将每个训练周期的损失值存储在 loss_history列表中：

```
loss_history = []
for _ in range(50):
    opt.zero_grad()
    loss_value = loss_func(mynet(X),Y)
    loss_value.backward()
    opt.step()
    loss_history.append(loss_value.item())
```

可以用 plot 绘制loss_history

实例化数据集的一个类 - MyDataset：

```
from torch.utils.data import Dataset, DataLoader

class MyDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x).float()
        self.y = torch.tensor(y).float()
    
    def __len__(self):
        return len(self.x)

    def __getitem__(self, ix):
        return self.x[ix], self.y[ix]
```

创建一个实例：

```
ds = MyDataset(X,Y)
```

将之前定义的数据集实例传入数据加载器 DataLoader，从原始输入和输出张量对象中获取 batch_size 数量的数据点：

```
dl = DataLoader(ds, batch_size = 2, shuffle = True)
# shuffle 打乱，获取数据数据
```

从 dl 中获取批处理：

```
for x, y in dl:
    print(x, y)
# tensor([[1,2],[3,4]]), tensor([[3],[7]])
# tensor([[5,6],[7,8]]), tensor([[1],[15]])
```

定义神经网络：

```
class MyNeuralNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.input_to_hidden_layer = nn.Linear(2,8)
        self.hidden_layer_activation = nn.ReLU()
        self.hidden_to_output_layer = nn.Linear(8,1)
    
    def forward(self, x):
        x = self.input_to_hidden_layer(x)
        x = self.hidden_layer_activation(x)
        x = self.hidden_to_output_layer(x)
        return x
```

定义模型对象，损失函数和优化器：

```
mynet = MyNeuralNet().to(device)
loss_func = nn.MSELoss()
opt = SGD(mynet.parameters(), lr = 0.001)
```

循环数据的批处理以最小化损失值：

```
loss_history = []
start = time.time()
for _ in range(50):
    for data in dl:
        x, y = data
        opt.zero_grad()
        loss_value = loss_func(mynet(x),y)
        loss_value.backward()
        opt.step()
        loss_history.append(loss_value.item())
end = time.time()
print(end - start)
```
