这里的两层 `for` 循环是在逐个计算所有权重参数的数值梯度：

```python
for i, layer in enumerate(original_weights):
    for index, weight in np.ndenumerate(layer):
```

- 外层循环遍历 `original_weights` 中的每一组参数。`i` 是参数组的下标，例如权重矩阵或偏置向量在列表中的位置，`layer` 是这一组参数。
- 内层循环遍历当前参数组里的每一个标量。`np.ndenumerate(layer)` 返回元素的多维下标 `index` 和对应的值 `weight`。例如二维矩阵中的 `index` 可能是 `(0, 1)`；这里并不需要直接使用 `weight`，只需要用 `index` 定位参数。

`enumerate` 是 Python 的内置函数。它遍历一个可迭代对象，并在每次循环中同时返回元素的序号和元素本身：

```python
for i, layer in enumerate(original_weights):
    print(i, layer)
```

对于下面的 `original_weights`，外层循环的结果是：

```text
i=0, layer=[[0.1, 0.2],
            [0.3, 0.4]]

i=1, layer=[[0.5],
            [0.6]]
```

也就是说，`enumerate(original_weights)` 只负责给每组参数编号，默认从 `0` 开始；它不会继续遍历 NumPy 数组内部的元素。深入矩阵并取得每个标量及其多维坐标，是内层 `np.ndenumerate(layer)` 的工作。

例如，假设 `original_weights` 中有两组参数：

```python
original_weights = [
    np.array([[0.1, 0.2],
              [0.3, 0.4]]),

    np.array([[0.5],
              [0.6]])
]
```

可以把它理解为：

```text
original_weights
├── 第 0 组：[[0.1, 0.2],
│             [0.3, 0.4]]
└── 第 1 组：[[0.5],
              [0.6]]
```

外层循环第一次执行时，`i = 0`，`layer` 是第 0 组的 $2 \times 2$ 矩阵。内层循环会依次得到：

```text
index=(0, 0), weight=0.1
index=(0, 1), weight=0.2
index=(1, 0), weight=0.3
index=(1, 1), weight=0.4
```

外层循环第二次执行时，`i = 1`，`layer` 是第 1 组的 $2 \times 1$ 矩阵。内层循环会依次得到：

```text
index=(0, 0), weight=0.5
index=(1, 0), weight=0.6
```

所以，两层循环总共执行 $4+2=6$ 次，每次只处理一个标量参数。`i` 用来确定参数属于哪一组，`index` 用来确定参数在这一组中的行、列位置。例如，`i = 0`、`index = (1, 0)` 定位的是 `original_weights[0][1, 0]`，也就是 `0.3`。

定位到一个参数后，代码先复制一份完整的 `weights`，只给当前参数加上一个很小的值 `0.0001`，再重新进行前向传播：

```python
temp_weights = deepcopy(weights)
temp_weights[i][index] += 0.0001
_loss_plus = feed_forward(inputs, outputs, temp_weights)
grad = (_loss_plus - original_loss) / 0.0001
```

以第一次内层循环为例，此时 `i = 0`、`index = (0, 0)`，被扰动的参数是 `0.1`：

```python
temp_weights[0][0, 0] += 0.0001
```

此时 `temp_weights` 变成：

```python
[
    np.array([[0.1001, 0.2],
              [0.3,    0.4]]),

    np.array([[0.5],
              [0.6]])
]
```

可以看到，只有 `0.1` 变成了 `0.1001`，其他参数都没有变化。假设原始损失为 `0.25`，扰动后的损失为 `0.25003`，那么这个参数的数值梯度为：

```python
grad = (0.25003 - 0.25) / 0.0001
     = 0.3
```

如果学习率 `lr = 0.1`，对应参数会被更新为：

```python
updated_weights[0][0, 0] = 0.1 - 0.3 * 0.1
                         = 0.07
```

接下来循环会恢复一份没有扰动过的 `weights`，再单独将 `0.2` 变成 `0.2001`，计算损失对 `0.2` 的梯度。后面的 `0.3`、`0.4`、`0.5` 和 `0.6` 也会重复同样的过程。

这实际上是在用有限差分近似偏导数：

$$
\frac{\partial L}{\partial w} \approx
\frac{L(w + \varepsilon) - L(w)}{\varepsilon}
$$

其中 $\varepsilon = 0.0001$。每次内层循环只扰动一个参数，因此得到的是损失函数对该参数的梯度。最后根据梯度下降公式更新相同位置的参数：

```python
updated_weights[i][index] -= grad * lr
```

两层循环结束后，权重矩阵和偏置向量中的每个参数都完成了一次更新。`temp_weights` 必须在内层循环中重新复制，否则前面参数的扰动会累积，后面算出的就不再是单个参数对应的偏导数。
