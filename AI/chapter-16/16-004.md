重新调整张量形状的另外一个方法是 squeeze，提供想要删除的轴索引。

需要注意的是，当我们想要删除的轴在这个维度上只有一个元素时，这种方法才适用

```
x = torch.randn(10,1,10)
z1 = torch.squeeze(x,1)
z2 = x.squeeze(1)           # 或者
```

逆运算

```
x = torch.randn(10,10)
# torch.Size([10, 10])
z1 = x.unsqueeze(0)
# torch.Size([1, 10, 10])
```

还用一种方法是

```
x = torch.randn(10,10)
z2 = x[None]

z3 = x[:,None]
# torch.Size([10, 1, 10])
z3 = x[:,:,None]
# torch.Size([10, 10, 1])
```

提取最大值以及最大值所在行的索引

```
# 在维度0上取最大值，在行的方向上
x.max(dim=0)
# values=tensor([20,21,22,23,24])
# indices=tensor([4,4,4,4,4])

# 在维度 1 上取最大值，在列的方向上
x.max(dim=1)
# values=tensor([4,9,14,19,24])
# indices=tensor([4,4,4,4,4])
```

重新排列一个张量对象的维度：

```
x = torch.randn(10,20,30)
z = x.permute(2,0,1)
print(x.shape)
# torch.Size([10,20,30])
print(z.shape)
# torch.Size([30,10,20])
```

不要使用 tensor.view 来交换维度，而是使用 permute：因为view 只是按内存顺序重新解释形状，不是移动维度


定义一个张量对象，并指定其需要计算的一个梯度：

```
x = torch.tensor([2.,-1.],[1.,1.], requires_grad=True)
print(x)
```

定义计算输出的方法：

```
out = x.pow(2).sum()
```

调用 backword 方法计算变量的梯度

```
out.backward()
```

获取输出 out 关于输入 x 的梯度：

```
x.grad
# tensor([4.,-2.],[2.,2.])
```

生成两个不同的 torch 对象：

```
x = torch.rand(1,6400)
y = torch.rand(6400, 5000)
```

定义将创建的张量对象存储到哪个设备：

```
device = 'cuda' if torch.cuda.is_available() else 'cpu'
```

```
x, y = x.to(device), y.to(device)
```

执行 torch 对象的矩阵乘法并计时

```
%timeit z=(x@y)
# 0.515 ms
```

在 cpu 上执行同样的张量矩阵乘法：

```
x,y = x.cpu(), y.cpu()
%timeit z=(x@y)
# 9 ms
```

用 numpy 数组执行同样的矩阵乘法

x = np.random.random((1,6400))
