重新调整张量形状的另外一个方法是 squeeze，提供想要删除的轴索引。

需要注意的是，当我们想要删除的轴在这个维度上只有一个元素时，这种方法才适用

```
x = torch.randn(10,1,10)
z1 = torch.squeeze(x,1)
z2 = x.squeeze(1)           # 或者
```

逆运算

```
x = torch.randn(10,10)
# torch.Size([10, 10])
z1 = x.unsqueeze(0)
# torch.Size([1, 10, 10])
```

还用一种方法是

```
x = torch.randn(10,10)
z2 = x[None]
# torch.Size([1, 10, 10])
z3 = x[:,None]
# torch.Size([10, 1, 10])
z3 = x[:,:,None]
# torch.Size([10, 10, 1])
```

矩阵乘法

```
x = torch.tensor([[1,2,3,4],[5,6,7,8]])
torch.matmul(x,y)
```

也可以使用@运算符

```
print(x@y)
```

使用 cat 方法实现张量的连接

```
x = torch.randn(10,10,10)
z = torch.cat([x,x],axis=0)
print(x.shape)
# torch.Size([10,10,10])
print(z.shape)
# torch.Size([20,10,10])
```

```
z = torch.cat([x,x], axis=1)
print(z.shape)
# torch.Size([10,20,10])
```
