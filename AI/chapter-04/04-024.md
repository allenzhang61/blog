# Bahdanau 注意力机制

Bahdanau 注意力机制是早期用于改进 RNN 编码器-解码器模型的一种注意力机制。它来自机器翻译任务，核心目标是解决一个问题：

```text
不要把整个源句子的信息都压缩进最后一个隐藏状态。
```

在没有注意力机制的 encoder-decoder RNN 中，编码器按顺序读完整个输入句子，最后得到一个隐藏状态，然后解码器只依赖这个最终隐藏状态生成目标句子。短句还可以，长句就很容易丢信息。

Bahdanau 注意力机制的改进是：解码器在生成每一个目标词时，都可以回头查看编码器在所有时间步产生的隐藏状态，并为不同位置分配不同权重。

## 1. 背景：普通 encoder-decoder RNN 的瓶颈

假设源语言句子是：

```text
I love deep learning
```

编码器 RNN 会按顺序读取：

```text
I -> love -> deep -> learning
```

每读一个词，编码器都会产生一个隐藏状态：

```text
h_1, h_2, h_3, h_4
```

没有注意力机制时，解码器通常主要依赖最后一个隐藏状态 `h_4` 作为整句话的表示：

```text
整句信息 -> h_4 -> 解码器生成翻译
```

问题在于：`h_4` 是一个固定长度向量。句子越长，越难把全部信息完整压进去。

这就是信息压缩瓶颈。

## 2. Bahdanau 注意力的核心想法

Bahdanau 注意力机制不再只使用最后一个隐藏状态，而是保留编码器每个时间步的隐藏状态：

```text
h_1, h_2, ..., h_T
```

当解码器要生成第 `t` 个目标词时，它会根据自己当前的解码状态，去判断源句子每个位置有多重要。

可以理解成：

```text
解码器当前想生成一个词
-> 去源句子每个位置查一遍
-> 给相关位置更高权重
-> 把这些位置的信息加权汇总
-> 用汇总后的上下文生成当前词
```

这个加权汇总得到的向量叫上下文向量（context vector）。

## 3. 计算流程

设编码器产生的隐藏状态为：

$$
h_1, h_2, \cdots, h_T
$$

解码器上一时刻的隐藏状态为：

$$
s_{t-1}
$$

Bahdanau 注意力在解码第 `t` 个词时，大致分三步。

### 3.1 计算注意力打分

先计算解码器状态 `s_{t-1}` 和每个编码器隐藏状态 `h_i` 的匹配程度：

$$
e_{t,i} = v_a^T \tanh(W_s s_{t-1} + W_h h_i)
$$

其中：

- `e_{t,i}`：解码第 `t` 个词时，对源句子第 `i` 个位置的注意力分数。
- `s_{t-1}`：解码器上一时刻的隐藏状态，表示“当前已经翻译到哪里”。
- `h_i`：编码器第 `i` 个位置的隐藏状态，表示“源句子第 i 个词附近的信息”。
- `W_s`、`W_h`、`v_a`：可训练参数。

这个打分函数是一个小型前馈神经网络，所以 Bahdanau 注意力也常被叫做 additive attention（加性注意力）。

直观理解：

```text
s_{t-1}：我现在想生成什么？
h_i：源句子第 i 个位置提供了什么信息？
e_{t,i}：这两个东西有多匹配？
```

### 3.2 使用 softmax 得到注意力权重

注意力分数 `e_{t,i}` 还不是概率，需要通过 softmax 归一化：

$$
\alpha_{t,i} =
\frac{\exp(e_{t,i})}
{\sum_{j=1}^{T} \exp(e_{t,j})}
$$

其中：

- `\alpha_{t,i}`：解码第 `t` 个词时，对源句子第 `i` 个位置的关注权重。
- 所有位置的注意力权重加起来等于 1。

如果 `\alpha_{t,3}` 最大，说明解码器当前最关注源句子的第 3 个位置。

### 3.3 加权求和得到上下文向量

有了注意力权重后，把所有编码器隐藏状态加权求和：

$$
c_t = \sum_{i=1}^{T} \alpha_{t,i} h_i
$$

其中：

- `c_t`：解码第 `t` 个词时使用的上下文向量。
- 它不是固定的，每个解码时间步都会重新计算。

这一步非常关键：解码器不再只看最后的 `h_T`，而是动态查看整个源句子的所有隐藏状态。

## 4. 一个直观例子

假设源句子是：

```text
I love deep learning
```

目标句子是：

```text
我 喜欢 深度 学习
```

当解码器要生成“深度”时，它可能会给 `deep` 更高权重：

| 源词 | I | love | deep | learning |
| --- | --- | --- | --- | --- |
| 注意力权重 | 0.05 | 0.10 | 0.75 | 0.10 |

于是上下文向量主要来自 `deep` 对应的隐藏状态。

当解码器要生成“学习”时，它可能会给 `learning` 更高权重：

| 源词 | I | love | deep | learning |
| --- | --- | --- | --- | --- |
| 注意力权重 | 0.03 | 0.07 | 0.15 | 0.75 |

注意力权重会随着解码步骤变化。也就是说，模型每生成一个词，都会重新决定应该看源句子的哪些位置。

## 5. 为什么叫加性注意力

Bahdanau 注意力的打分函数是：

$$
e_{t,i} = v_a^T \tanh(W_s s_{t-1} + W_h h_i)
$$

这里先把两个向量分别线性变换，然后相加，再经过 `tanh` 和向量投影得到分数。

因为它通过“相加 + 小型神经网络”来计算匹配分数，所以叫 additive attention。

对比后来的 Luong attention，Luong 更常用点积或双线性形式：

$$
score(s_t, h_i) = s_t^T h_i
$$

或者：

$$
score(s_t, h_i) = s_t^T W h_i
$$

所以可以粗略记：

```text
Bahdanau attention：加性注意力，用小网络算匹配分数。
Luong attention：乘性注意力，用点积或矩阵乘法算匹配分数。
```

## 6. Bahdanau 注意力解决了什么

### 6.1 缓解信息压缩瓶颈

没有注意力时：

```text
源句子所有信息 -> 最后隐藏状态 h_T
```

有 Bahdanau 注意力后：

```text
源句子所有隐藏状态 h_1...h_T 都保留
解码每一步都可以动态访问它们
```

这样就不用把全部信息都塞进一个固定向量。

### 6.2 更容易处理长距离依赖

如果源句子里某个很早的词对当前翻译很重要，注意力机制可以直接给它高权重。

这比让信息一步步穿过 RNN 隐藏状态更直接。

### 6.3 可解释性更强

注意力权重可以画成矩阵：

```text
目标词 x 源词 -> 注意力热力图
```

在翻译任务里，经常能看到目标词和源词之间的对齐关系。

例如：

```text
生成“学习”时，模型主要关注 learning。
生成“深度”时，模型主要关注 deep。
```

## 7. 和 Transformer 自注意力的关系

Bahdanau 注意力和 Transformer 自注意力都在做“根据相关性加权汇总信息”，但它们的使用场景不同。

| 对比项 | Bahdanau 注意力 | Transformer 自注意力 |
| --- | --- | --- |
| 常见场景 | RNN encoder-decoder 翻译模型 | Transformer / GPT / BERT |
| 查询来自哪里 | 解码器隐藏状态 | 当前序列自身的 token |
| 被关注对象 | 编码器所有隐藏状态 | 同一序列中的所有 token |
| 是否依赖 RNN | 通常依赖 RNN | 不依赖 RNN |
| 计算方式 | 加性打分 | Q、K、V 点积注意力 |

Bahdanau 注意力可以看作一个重要过渡：

```text
普通 encoder-decoder RNN
-> 加入注意力机制的 RNN
-> 完全基于自注意力的 Transformer
```

它不是 Transformer，但它让“模型应该动态关注相关位置”这个思想变得非常清晰。

## 8. 极简伪代码

下面用伪代码表示 Bahdanau 注意力在解码第 `t` 步的计算。

```python
# encoder_states: [h_1, h_2, ..., h_T]
# decoder_state: s_{t-1}

scores = []
for h_i in encoder_states:
    score_i = v_a.T @ tanh(W_s @ decoder_state + W_h @ h_i)
    scores.append(score_i)

alpha = softmax(scores)

context = 0
for alpha_i, h_i in zip(alpha, encoder_states):
    context += alpha_i * h_i

# context 和 decoder_state 一起用于生成当前目标词
y_t = decoder(context, decoder_state)
```

抓住这三步就够了：

```text
打分 score
-> softmax 得到权重 alpha
-> 加权求和得到 context
```

## 9. 学习时的主线

学习 Bahdanau 注意力，可以抓住这条线：

```text
普通 RNN encoder-decoder 只能依赖最后隐藏状态
-> 长句信息容易丢失
-> 保留 encoder 每个时间步的隐藏状态
-> decoder 每生成一个词，就计算一次对所有 encoder 状态的注意力权重
-> 用加权求和得到 context vector
-> context 帮助 decoder 生成当前词
```
