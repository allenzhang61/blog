# RNN 算法理解：从序列记忆到注意力机制

RNN（Recurrent Neural Network，循环神经网络）是一类专门处理序列数据的神经网络。它的核心想法很朴素：处理当前输入时，不只看当前输入，还要带着前面已经看过的信息一起判断。

比如一句话：

```text
这部电影一点也不好
```

如果模型只看最后一个词“好”，很容易误判为正向情感；但如果它记住了前面的“一点也不”，就能判断整句话是负向情感。RNN 要解决的正是这种“前文会影响当前含义”的问题。

## 1. RNN 在解决什么问题

普通前馈神经网络默认每个样本之间彼此独立，输入一次，输出一次，不保留历史状态。

但很多数据天然有顺序：

- 文本：前面的词会影响后面的词。
- 时间序列：过去的温度、股价、流量会影响下一步。
- 语音：前面的音素会影响当前音素的理解。
- 翻译：源语言句子的整体含义会影响目标语言生成。

RNN 引入了一个隐藏状态 `h_t`，用来保存到当前时间步为止的上下文信息。

可以把隐藏状态理解成模型的“短期记忆”：

```text
当前输入 x_t + 上一步记忆 h_{t-1} -> 当前记忆 h_t -> 当前输出 y_t
```

## 2. RNN 的基本计算过程

设输入序列为：

$$
x_1, x_2, \cdots, x_T
$$

RNN 在每个时间步都会更新隐藏状态：

$$
h_t = \tanh(x_t W_{xh} + h_{t-1} W_{hh} + b_h)
$$

如果需要在每个时间步都有输出，可以写成：

$$
y_t = h_t W_{hy} + b_y
$$

其中：

- `x_t`：第 `t` 个时间步的输入。
- `h_t`：第 `t` 个时间步的隐藏状态。
- `h_{t-1}`：上一个时间步留下来的隐藏状态。
- `W_{xh}`：输入到隐藏状态的权重。
- `W_{hh}`：隐藏状态到隐藏状态的循环权重。
- `W_{hy}`：隐藏状态到输出的权重。
- `tanh`：非线性激活函数，把状态值压到 `(-1, 1)` 之间。

RNN 和普通神经网络最大的区别在 `h_{t-1} W_{hh}` 这一项：它让模型可以把上一步的信息传到下一步。

## 3. 一个直观例子

假设我们要预测一句话的情感：

```text
这 / 部 / 电影 / 不 / 好
```

RNN 会按顺序读：

```text
读到“这”：h_1 记录“这”
读到“部”：h_2 记录“这部”
读到“电影”：h_3 记录“这部电影”
读到“不”：h_4 记录“这部电影不”
读到“好”：h_5 结合“不”和“好”，判断整体偏负向
```

最后可以用 `h_5` 做分类：

```text
h_5 -> 全连接层 -> 正向 / 负向
```

这类结构叫 many-to-one：输入是多个时间步，最后只输出一个结果。

## 4. RNN 的几种常见输入输出形式

### 4.1 One-to-Many

一个输入，生成一串输出。

例子：输入一张图片，生成一句图片描述。

```text
图片 -> 一个 / 小孩 / 在 / 跑步
```

### 4.2 Many-to-One

一串输入，输出一个结果。

例子：情感分析。

```text
一段评论 -> 好评 / 差评
```

### 4.3 Many-to-Many

一串输入，输出一串结果。

例子：机器翻译。

```text
I love you -> 我 爱 你
```

在 Transformer 出现之前，RNN 是机器翻译里常见的编码器-解码器结构。

## 5. 编码器-解码器 RNN

在翻译任务中，通常会把 RNN 分成两部分：

- 编码器（Encoder）：按顺序读完整个源语言句子。
- 解码器（Decoder）：根据编码器留下来的信息，逐词生成目标语言句子。

例如：

```text
Encoder 读取：I love you
Encoder 得到最后隐藏状态 h_T
Decoder 使用 h_T 生成：我 爱 你
```

这里的关键是：编码器会试图把整个输入句子的含义压缩到最后一个隐藏状态中。

这个最后隐藏状态可以理解成一个“句子向量”：

```text
整个输入句子 -> 一个隐藏状态向量
```

短句时，这种方式还能工作；句子很长时，问题就明显了。

## 6. RNN 的核心问题

### 6.1 信息压缩瓶颈

编码器-解码器 RNN 需要把整句话的信息压进最后一个隐藏状态。

如果句子很短，例如：

```text
I love you
```

一个隐藏状态可能还能保存主要信息。

如果句子很长，例如：

```text
The cat, who was sitting on the windowsill, jumped down because it saw a bird flying outside the window.
```

模型要在读到 `it` 时知道它指的是 `the cat`，而不是 `windowsill`。但 `the cat` 出现在很前面，经过许多时间步之后，这个信息可能已经被后续词语冲淡。

这就是长距离依赖问题。

### 6.2 梯度消失和梯度爆炸

RNN 训练时使用 BPTT（Backpropagation Through Time，随时间反向传播）。

普通反向传播只沿网络层传播梯度；BPTT 还要沿时间轴往回传播：

```text
t = T -> T-1 -> T-2 -> ... -> 1
```

如果序列很长，梯度在反复乘以权重矩阵时可能越来越小，导致早期时间步几乎学不到东西，这叫梯度消失。

也可能越来越大，导致训练不稳定，这叫梯度爆炸。

### 6.3 难以并行

RNN 必须按顺序计算：

```text
h_1 算完 -> 才能算 h_2
h_2 算完 -> 才能算 h_3
```

所以它不适合大规模并行训练。

Transformer 的自注意力机制可以一次性处理整段序列，训练效率更高。

## 7. 注意力机制为什么出现

RNN 的问题不是完全不能记忆，而是它太依赖最后一个隐藏状态。

注意力机制的核心改进是：解码器不只看最后一个隐藏状态，而是可以在生成每个词时，直接查看编码器在所有时间步产生的隐藏状态。

可以从：

```text
只能看最后一个状态
```

变成：

```text
需要哪个位置的信息，就重点关注哪个位置
```

例如处理 `it` 时，模型可以直接给 `the cat` 更高的注意力权重。

这就缓解了长距离依赖问题。

## 8. RNN 与自注意力的对比

| 对比项 | RNN | 自注意力机制 |
| --- | --- | --- |
| 信息传递方式 | 通过隐藏状态逐步传递 | 任意位置之间可以直接建立联系 |
| 长距离依赖 | 容易遗忘早期信息 | 更容易直接访问远处 token |
| 并行能力 | 弱，必须顺序计算 | 强，可以并行计算整段序列 |
| 典型问题 | 梯度消失、信息压缩瓶颈 | 计算量随序列长度平方增长 |
| 代表模型 | RNN、LSTM、GRU | Transformer、GPT、BERT |

## 9. RNN、LSTM、GRU 的关系

普通 RNN 的记忆能力有限，所以后来出现了 LSTM 和 GRU。

它们仍然属于循环神经网络家族，但引入了“门控机制”：

- LSTM：通过输入门、遗忘门、输出门控制信息流。
- GRU：结构比 LSTM 简洁，用更新门和重置门控制信息流。

门控机制的作用是让模型学会：

```text
哪些信息该记住
哪些信息该忘掉
哪些信息该输出
```

所以可以粗略理解为：

```text
RNN：基础循环记忆
LSTM / GRU：更聪明、更稳定的循环记忆
Transformer：不再按顺序传递记忆，而是直接用注意力建立 token 之间的关系
```

## 10. 学习 RNN 时要抓住的主线

学习 RNN 不要一开始陷入复杂公式，可以抓住这条线：

```text
序列数据有顺序
-> 普通神经网络没有记忆
-> RNN 用隐藏状态保存历史信息
-> 长序列中隐藏状态会成为瓶颈
-> 注意力机制允许模型直接关注序列中相关位置
-> Transformer 用自注意力替代循环结构
```

## 11. 极简伪代码

```python
h = zeros(hidden_size)

for x_t in sequence:
    h = tanh(x_t @ W_xh + h @ W_hh + b_h)

y = h @ W_hy + b_y
```

这段伪代码就是 RNN 的灵魂：

- `h` 是记忆。
- `x_t` 是当前输入。
- 每读一个新 token，就更新一次记忆。
- 最后用记忆做预测。

## 12. 和 04-022 的关系

[04-022.ipynb](./04-022.ipynb) 是一个 NumPy 实现的 RNN 正弦波预测案例。

这篇笔记先解释“为什么需要 RNN、RNN 怎么记忆、为什么长序列困难”；再去看 04-022 的代码时，可以重点对应这些概念：

- `h_states`：每个时间步保存的隐藏状态。
- `W_xh`：当前输入如何影响隐藏状态。
- `W_hh`：上一时刻隐藏状态如何影响当前隐藏状态。
- `W_hy`：最后隐藏状态如何变成预测输出。
- `backward`：BPTT，沿时间轴反向传播梯度。
