# Qwen3.5 Model 流程图

这篇记录当前 `llm-inference-cpp/src/model` 下的 Module 结构。它描述的是 decode 阶段的模型 forward 形状；prefill 的 batch path 仍由 `QwenDecoder::prefill(...) -> cuda_prefill_batch(...)` 单独处理。

## 顶层结构

```text
QwenGenerator
  |
  +-- generate(...)
  |     |
  |     +-- QwenModel::prefill(prompt_ids, RunState)
  |     |
  |     +-- loop max_new_tokens:
  |           |
  |           +-- QwenModel::forward_lm_head(hidden) -> next token id
  |           |
  |           +-- QwenModel::forward(next token id, RunState)

QwenModel
  |
  +-- prefill(prompt ids, RunState) -> QwenDecoder::prefill
  |
  +-- forward(device token id, RunState) -> QwenDecoder::forward
  |
  +-- forward_lm_head(hidden, device token slot) -> QwenLmHead::forward
```

`QwenGenerator::generate(...)` 是生成循环编排，`QwenModel::forward(...)` 是单 token 模型前向。生成出来的 token id 留在 CUDA device buffer 中，下一轮直接作为 `QwenDecoder::forward(...)` 的输入。

## Decode Forward

```text
device token id
    |
    v
TokenEmbedding::forward
    |
    v
hidden
    |
    v
QwenDecoder
    |
    +-- QwenBlock[0]
    +-- QwenBlock[1]
    +-- ...
    +-- QwenBlock[31]
    |
    v
hidden
    |
    v
QwenLmHead::forward
    |
    v
next token id
```

`QwenDecoder` 按 `config.text.layer_types` 构造不同 block：

```text
layer.type == "linear_attention" -> QwenLinearAttentionBlock  // Gated DeltaNet
layer.type == "full_attention"   -> QwenFullAttentionBlock
```

构造时选择具体 Module，decode forward 时不再判断 layer type，只执行：

```text
current = block->forward(current, state)
```

## Linear Attention Block

```text
QwenLinearAttentionBlock::forward(x)
    |
    v
input RMSNorm
    |
    v
QwenLinearAttention::forward(normed_x)
    |
    v
attention mixer output
    |
    v
residual add + post RMSNorm
    |
    v
QwenMlp::forward(post_normed)
    |
    v
MLP output
    |
    v
residual add
    |
    v
block output
```

`QwenLinearAttention` 对应 Qwen3.5 的 `linear_attention` 层，也就是 Gated DeltaNet。内部流程：

```text
normed_x
    |
    +-- in_proj_qkv
    +-- in_proj_z
    +-- in_proj_b
    +-- in_proj_a
    |
    v
linear attention conv
    |
    v
linear recurrent state update
    |
    v
gated RMSNorm
    |
    v
out_proj
    |
    v
mixer output
```

它会更新 `RunState.linear[layer].cuda_state`：

```text
conv_state
recurrent_state
```

## Full Attention Block

```text
QwenFullAttentionBlock::forward(x)
    |
    v
input RMSNorm
    |
    v
QwenFullAttention::forward(normed_x)
    |
    v
attention mixer output
    |
    v
residual add + post RMSNorm
    |
    v
QwenMlp::forward(post_normed)
    |
    v
MLP output
    |
    v
residual add
    |
    v
block output
```

`QwenFullAttention` 内部流程：

```text
normed_x
    |
    +-- q_proj
    +-- k_proj
    +-- v_proj
    |
    v
q_norm + RoPE
    |
    +--------------+
                   |
k_norm + RoPE     |
    |              |
    v              |
写入 KV cache      |
    |              |
    +--------------+
                   |
                   v
causal attention over KV cache
    |
    v
o_proj
    |
    v
mixer output
```

它会更新 `RunState.full[layer].cuda_state`：

```text
key_cache
value_cache
```

## MLP 子模块

`QwenMlp` 被 linear attention block 和 full attention block 复用，是 SwiGLU-style gate/up/down 结构：

```text
post_normed
    |
    +-- gate_proj
    +-- up_proj
    |
    v
SiLU(gate) * up
    |
    v
down_proj
    |
    v
MLP output
```

## 当前 Module 层级

```text
QwenModel
  |
  +-- QwenDecoder
  |     |
  |     +-- TokenEmbedding
  |     |
  |     +-- vector<unique_ptr<QwenBlock>>
  |           |
  |           +-- QwenLinearAttentionBlock
  |           |     |
  |           |     +-- QwenLinearAttention
  |           |     +-- QwenMlp
  |           |
  |           +-- QwenFullAttentionBlock
  |                 |
  |                 +-- QwenFullAttention
  |                 +-- QwenMlp
  |
  +-- QwenLmHead

QwenGenerator
  |
  +-- const QwenModel&
```

对应文件：

```text
Tensor.h                     forward 中流动的 CUDA runtime tensor
Module.h                     Module 基类
Embedding.cpp/.h             TokenEmbedding
QwenModel.cpp/.h             模型结构、prefill、单 token forward 和 lm head 入口
QwenGenerator.cpp/.h         greedy 生成循环、timing 和输出 token 管理
QwenDecoder.cpp/.h           block 堆叠和 prefill/decode 分发
QwenBlock.cpp/.h             block 抽象基类和输出 hidden buffer 分配
QwenLinearAttentionBlock.*   linear attention block 编排
QwenLinearAttention.*        linear attention mixer, 对应 Gated DeltaNet
QwenFullAttentionBlock.*     full attention block 编排
QwenFullAttention.*          full attention mixer
QwenMlp.*                    MLP 子模块，SwiGLU-style gate/up/down
QwenLmHead.*                 final norm + lm head + greedy argmax
runtime_state.*              linear/full attention 运行时 cache
weights.*                    WeightData 结构化绑定
```
