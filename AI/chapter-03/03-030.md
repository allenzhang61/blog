# 使用 CommitPackFT 对 Qwen2.5-Coder 做 Go Commit Message LoRA 微调

这一节做一个更接近真实工程的小实验：使用 Hugging Face 上的 `bigcode/commitpackft` 数据集，抽取 Go 语言子集，对 `Qwen/Qwen2.5-Coder-1.5B-Instruct` 做 LoRA 微调，让模型根据 `git diff` 生成简短的 commit message。

这类任务很适合 LoRA：基础模型已经具备代码理解能力，我们只需要让它适应“看到 diff 后输出提交说明”的格式和风格，不需要全量微调 15 亿参数。

## 1. 实验目标

输入是一段 Go 文件变更的 unified diff：

```diff
--- loadavg_stub.go
+++ loadavg_stub.go
@@ ...
```

输出是简短 commit message：

```text
Fix stub for loadavg function.
```

本次训练使用：

- 基座模型：`Qwen/Qwen2.5-Coder-1.5B-Instruct`
- 数据集：`bigcode/commitpackft`
- 数据分片：`go`
- 微调方式：LoRA
- LoRA target modules：`q_proj`、`k_proj`、`v_proj`、`o_proj`
- 训练样本：从 Go 分片随机抽取 5000 条，清洗后 4979 条
- 验证样本：100 条
- 设备：Apple Silicon MPS

## 2. 环境准备

在项目目录下创建虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip setuptools wheel
```

安装训练依赖：

```bash
pip install -U torch peft accelerate
pip install 'transformers<5.0.0' 'trl<1.0.0' 'datasets<4.0.0'
```

这里有两个版本细节值得注意。

第一，`bigcode/commitpackft` 使用了数据集加载脚本，新版 `datasets 5.x` 会报错：

```text
RuntimeError: Dataset scripts are no longer supported, but found commitpackft.py
```

所以这里固定 `datasets<4.0.0`。

第二，教程里常见的 `device_map="auto"` 更适合 CUDA 场景。在 macOS + Apple Silicon 上，本次实验改成自动选择 `mps`，避免模型加载卡在自动设备分配路径上。

## 3. 完整训练代码

保存为 `train_lora_go_commit.py`：

```python
#!/usr/bin/env python3
"""
LoRA fine-tuning script for Go commit message generation.

Install dependencies first, for example:
    pip install -U torch transformers datasets peft trl accelerate

Example:
    python train_lora_go_commit.py --sample-size 5000
"""

from __future__ import annotations

import argparse
import difflib
import inspect
from typing import Any

import torch
from datasets import load_dataset
from peft import LoraConfig, TaskType, get_peft_model
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,
    DataCollatorForLanguageModeling,
    Trainer,
    TrainingArguments,
)
from trl import SFTTrainer


def parse_args() -> argparse.Namespace:
    parser = argparse.ArgumentParser(
        description="Fine-tune Qwen2.5-Coder with LoRA on bigcode/commitpackft Go diffs."
    )
    parser.add_argument("--model-id", default="Qwen/Qwen2.5-Coder-1.5B-Instruct")
    parser.add_argument("--dataset-name", default="bigcode/commitpackft")
    parser.add_argument("--dataset-config", default="go")
    parser.add_argument("--split", default="train")
    parser.add_argument("--sample-size", type=int, default=5000)
    parser.add_argument(
        "--eval-size",
        type=int,
        default=0,
        help="Hold out this many cleaned examples for one evaluation pass after training.",
    )
    parser.add_argument("--max-diff-chars", type=int, default=2000)
    parser.add_argument("--min-message-chars", type=int, default=10)
    parser.add_argument("--max-seq-length", type=int, default=1536)
    parser.add_argument("--output-dir", default="./lora-go-commit-checkpoint")
    parser.add_argument("--final-output-dir", default="./lora-go-commit-final")
    parser.add_argument("--per-device-train-batch-size", type=int, default=4)
    parser.add_argument("--gradient-accumulation-steps", type=int, default=4)
    parser.add_argument("--learning-rate", type=float, default=2e-4)
    parser.add_argument("--num-train-epochs", type=float, default=2.0)
    parser.add_argument("--logging-steps", type=int, default=10)
    parser.add_argument("--seed", type=int, default=42)
    parser.add_argument("--lora-r", type=int, default=16)
    parser.add_argument("--lora-alpha", type=int, default=32)
    parser.add_argument("--lora-dropout", type=float, default=0.05)
    parser.add_argument(
        "--device",
        choices=["auto", "cuda", "mps", "cpu"],
        default="auto",
        help="Training device. auto prefers CUDA, then Apple Silicon MPS, then CPU.",
    )
    parser.add_argument("--use-fp16", action="store_true", help="Use FP16 instead of BF16.")
    parser.add_argument(
        "--gradient-checkpointing",
        action="store_true",
        help="Save memory at the cost of slower training.",
    )
    return parser.parse_args()


def has_bf16_support() -> bool:
    return torch.cuda.is_available() and torch.cuda.is_bf16_supported()


def resolve_device(requested_device: str) -> str:
    if requested_device != "auto":
        return requested_device
    if torch.cuda.is_available():
        return "cuda"
    if torch.backends.mps.is_available():
        return "mps"
    return "cpu"


def format_prompt(example: dict[str, Any]) -> dict[str, str]:
    diff = get_diff_text(example)
    message = get_message_text(example)
    text = (
        "<|im_start|>system\n"
        "你是一个高级后端开发工程师。请根据以下 git diff 内容，"
        "生成简短且符合 Conventional Commits 规范的总结。<|im_end|>\n"
        f"<|im_start|>user\n{diff}<|im_end|>\n"
        f"<|im_start|>assistant\n{message}<|im_end|>"
    )
    return {"text": text}


def get_diff_text(example: dict[str, Any]) -> str:
    if example.get("diff"):
        return str(example["diff"])

    old_contents = example.get("old_contents") or ""
    new_contents = example.get("new_contents") or ""
    old_file = example.get("old_file") or "old_file"
    new_file = example.get("new_file") or "new_file"

    return "".join(
        difflib.unified_diff(
            str(old_contents).splitlines(keepends=True),
            str(new_contents).splitlines(keepends=True),
            fromfile=str(old_file),
            tofile=str(new_file),
            lineterm="",
        )
    )


def get_message_text(example: dict[str, Any]) -> str:
    return str(example.get("subject") or example.get("message") or "").strip()


def load_and_prepare_dataset(args: argparse.Namespace):
    print("正在下载并加载数据集...")
    dataset = load_dataset(args.dataset_name, args.dataset_config, split=args.split)

    sample_size = min(args.sample_size, len(dataset))
    dataset = dataset.shuffle(seed=args.seed).select(range(sample_size))

    def filter_length(example: dict[str, Any]) -> bool:
        diff = get_diff_text(example)
        message = get_message_text(example)
        return len(diff) < args.max_diff_chars and len(message) > args.min_message_chars

    dataset = dataset.filter(filter_length)
    dataset = dataset.map(format_prompt)
    print(f"清洗后的有效数据量: {len(dataset)}")

    if args.eval_size <= 0:
        return dataset, None

    eval_size = min(args.eval_size, max(len(dataset) - 1, 0))
    split = dataset.train_test_split(test_size=eval_size, seed=args.seed)
    print(f"训练集: {len(split['train'])}, 验证集: {len(split['test'])}")
    return split["train"], split["test"]


def load_model_and_tokenizer(args: argparse.Namespace):
    print(f"正在加载模型: {args.model_id} ...")
    tokenizer = AutoTokenizer.from_pretrained(args.model_id, trust_remote_code=True)
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
    tokenizer.padding_side = "right"

    device = resolve_device(args.device)
    use_bf16 = device == "cuda" and has_bf16_support() and not args.use_fp16
    if device == "cuda":
        dtype = torch.float16 if args.use_fp16 else (torch.bfloat16 if use_bf16 else torch.float32)
        model_kwargs = {"device_map": "auto"}
    elif device == "mps":
        dtype = torch.float16
        model_kwargs = {}
    else:
        dtype = torch.float32
        model_kwargs = {}

    print(f"使用设备: {device}, dtype: {dtype}")
    model = AutoModelForCausalLM.from_pretrained(
        args.model_id,
        torch_dtype=dtype,
        trust_remote_code=True,
        **model_kwargs,
    )
    if device in {"mps", "cpu"}:
        model = model.to(device)
    model.config.use_cache = False

    if args.gradient_checkpointing:
        model.gradient_checkpointing_enable()

    return model, tokenizer, use_bf16


def attach_lora(model, args: argparse.Namespace):
    lora_config = LoraConfig(
        task_type=TaskType.CAUSAL_LM,
        r=args.lora_r,
        lora_alpha=args.lora_alpha,
        target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
        lora_dropout=args.lora_dropout,
        bias="none",
    )
    model = get_peft_model(model, lora_config)
    model.print_trainable_parameters()
    return model


def build_training_args(args: argparse.Namespace, use_bf16: bool, has_eval_dataset: bool) -> TrainingArguments:
    device = resolve_device(args.device)
    use_fp16 = (args.use_fp16 and device == "cuda") or device == "mps"
    training_kwargs = {
        "output_dir": args.output_dir,
        "per_device_train_batch_size": args.per_device_train_batch_size,
        "gradient_accumulation_steps": args.gradient_accumulation_steps,
        "learning_rate": args.learning_rate,
        "num_train_epochs": args.num_train_epochs,
        "logging_steps": args.logging_steps,
        "save_strategy": "epoch",
        "bf16": use_bf16,
        "fp16": use_fp16,
        "optim": "adamw_torch",
        "report_to": "none",
        "seed": args.seed,
    }

    if has_eval_dataset:
        training_kwargs["do_eval"] = True
        training_args_params = inspect.signature(TrainingArguments.__init__).parameters
        if "eval_strategy" in training_args_params:
            training_kwargs["eval_strategy"] = "no"
        else:
            training_kwargs["evaluation_strategy"] = "no"

    return TrainingArguments(**training_kwargs)


def build_sft_trainer(model, tokenizer, train_dataset, eval_dataset, training_args, max_seq_length: int):
    """Create SFTTrainer across common TRL versions."""
    trainer_kwargs = {
        "model": model,
        "train_dataset": train_dataset,
        "args": training_args,
    }
    trainer_params = inspect.signature(SFTTrainer.__init__).parameters

    if "tokenizer" in trainer_params:
        trainer_kwargs["tokenizer"] = tokenizer
    elif "processing_class" in trainer_params:
        trainer_kwargs["processing_class"] = tokenizer

    if "dataset_text_field" in trainer_params:
        trainer_kwargs["dataset_text_field"] = "text"
    if "max_seq_length" in trainer_params:
        trainer_kwargs["max_seq_length"] = max_seq_length
    if eval_dataset is not None:
        trainer_kwargs["eval_dataset"] = eval_dataset

    return SFTTrainer(**trainer_kwargs)


def tokenize_dataset(tokenizer, dataset, max_seq_length: int):
    if dataset is None:
        return None

    def tokenize(batch):
        return tokenizer(
            batch["text"],
            truncation=True,
            max_length=max_seq_length,
            padding=False,
        )

    return dataset.map(
        tokenize,
        batched=True,
        remove_columns=dataset.column_names,
    )


def build_fallback_trainer(model, tokenizer, train_dataset, eval_dataset, training_args, max_seq_length: int):
    print("SFTTrainer 参数不兼容，自动切换到 transformers.Trainer 训练路径...")
    tokenized_train_dataset = tokenize_dataset(tokenizer, train_dataset, max_seq_length)
    tokenized_eval_dataset = tokenize_dataset(tokenizer, eval_dataset, max_seq_length)
    collator = DataCollatorForLanguageModeling(tokenizer=tokenizer, mlm=False)
    return Trainer(
        model=model,
        args=training_args,
        train_dataset=tokenized_train_dataset,
        eval_dataset=tokenized_eval_dataset,
        data_collator=collator,
    )


def main() -> None:
    args = parse_args()
    train_dataset, eval_dataset = load_and_prepare_dataset(args)
    model, tokenizer, use_bf16 = load_model_and_tokenizer(args)
    model = attach_lora(model, args)
    training_args = build_training_args(args, use_bf16, eval_dataset is not None)

    try:
        trainer = build_sft_trainer(
            model=model,
            tokenizer=tokenizer,
            train_dataset=train_dataset,
            eval_dataset=eval_dataset,
            training_args=training_args,
            max_seq_length=args.max_seq_length,
        )
    except TypeError as exc:
        print(f"SFTTrainer 初始化失败: {exc}")
        trainer = build_fallback_trainer(
            model=model,
            tokenizer=tokenizer,
            train_dataset=train_dataset,
            eval_dataset=eval_dataset,
            training_args=training_args,
            max_seq_length=args.max_seq_length,
        )

    print("开始训练...")
    trainer.train()

    if eval_dataset is not None:
        print("开始验证...")
        metrics = trainer.evaluate()
        print(f"验证结果: {metrics}")

    model.save_pretrained(args.final_output_dir)
    tokenizer.save_pretrained(args.final_output_dir)
    print(f"训练完成！LoRA 权重已保存至: {args.final_output_dir}")


if __name__ == "__main__":
    main()
```

## 7. 小结

这次实验里，最重要的不是 LoRA 参数本身，而是把数据集、prompt、设备和版本这些工程细节处理顺。

几个关键点：

- `commitpackft` 的 Go 分片实际字段是 `old_contents/new_contents/subject/message`，不是总有现成的 `diff` 字段，所以代码里用 `difflib.unified_diff` 生成 diff。
- 新版 `datasets 5.x` 不支持该数据集的加载脚本，所以使用 `datasets<4.0.0`。
- macOS 上优先使用 `mps`，CUDA 环境再使用 `device_map="auto"`。
- 用 4879 条训练样本、100 条验证样本，2 个 epoch 后验证损失达到 `0.8996`。
- LoRA 只训练约 `0.28%` 参数，就能让模型明显适应 commit message 生成任务。

如果后续要进一步提升效果，可以扩大样本量、提高 `max_seq_length`，或者把 prompt 改成更严格的 Conventional Commits 格式，例如要求输出必须以 `fix:`、`feat:`、`refactor:` 等前缀开头。
