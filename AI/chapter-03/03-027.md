# vllm 调用链

```
llm = LLM(
        model="facebook/opt-125m",
        enforce_eager=True,
        gpu_memory_utilization=0.3,
    )
```

```
examples/basic/offline_inference/basic.py
  -> vllm.LLM(...)
  -> vllm/entrypoints/llm.py
  -> EngineArgs
  -> LLMEngine.from_engine_args(...)
  -> vllm/v1/engine/llm_engine.py
  -> EngineCore / Executor / Worker
  -> vllm/v1/worker/cpu_worker.py
  -> CPUModelRunner
  -> vllm/platforms/cpu.py import_kernels()
  -> import vllm._C
  -> csrc/cpu/torch_bindings.cpp 注册 torch ops
  -> vllm/_custom_ops.py 调 torch.ops._C.xxx(...)
  -> C++ / CPU kernel 执行
```
