# 大模型评测工具

GitHub star 数为 2026-07-30 查询值，仅作工具热度参考。

评测工具通常不是一个工具覆盖所有指标，而是按评测目标组合使用：

- 基础能力：`lm-evaluation-harness` (13.5k stars)、`OpenCompass` (7.2k stars)、`LightEval` (2.5k stars)、`HELM` (2.9k stars)
- 指令与偏好：`AlpacaEval` (2k stars)、`FastChat/MT-Bench` (39.5k stars)、`promptfoo` (23.8k stars)
- 代码能力：`EvalPlus` (1.8k stars)、`bigcode-evaluation-harness` (1.1k stars)
- RAG / Agent：`Ragas` (15k stars)、`DeepEval` (17.3k stars)、`TruLens` (3.5k stars)、`Phoenix` (10.8k stars)、`promptfoo` (23.8k stars)
- 安全与红队：`garak` (8.6k stars)、`Giskard` (5.7k stars)、`promptfoo` (23.8k stars)
- 性能压测：`LLMPerf` (1.1k stars)、`vLLM Benchmark CLI` (87.7k stars)、`AIPerf` (482 stars)

## 常用工具定位

| 工具 | 主要用途 | 备注 |
|------|----------|------|
| `lm-evaluation-harness` (13.5k stars) | 通用 LLM benchmark | EleutherAI 维护，常用于 MMLU、GSM8K、HellaSwag 等标准任务 |
| `OpenCompass` (7.2k stars) | 大模型综合评测平台 | 覆盖模型、数据集和能力维度较多，中文生态里也比较常见 |
| `LightEval` (2.5k stars) | Hugging Face 评测工具 | 适合多后端、样本级结果分析和 leaderboard 风格评测 |
| `HELM` (2.9k stars) | Holistic Evaluation | 更强调透明、可复现、多维度评测，包括准确性、鲁棒性、公平性等 |
| `EvalPlus` (1.8k stars) | 代码生成评测 | HumanEval+、MBPP+ 测试更严格，适合看 Pass@k |
| `bigcode-evaluation-harness` (1.1k stars) | 代码模型评测 | 适合代码生成模型和多种代码 benchmark |
| `VLMEvalKit` (4.3k stars) | 多模态模型评测 | 适合 VLM/LMM 的图文理解、OCR、VQA 等任务 |
| `LongBench` (1.2k stars) | 长上下文评测 | 用于评测模型处理长文档、长上下文推理的能力 |
| `AlpacaEval` (2k stars) | 指令模型自动偏好评测 | 通过 pairwise judge 计算 win rate，适合 chat model 对比 |
| `FastChat/MT-Bench` (39.5k stars) | 多轮对话评测 | 用 LLM-as-a-judge 给开放式多轮回答打分 |
| `Ragas` (15k stars) | RAG 评测 | 常看 faithfulness、answer relevance、context precision/recall |
| `DeepEval` (17.3k stars) | LLM 应用单元测试 | 类似 pytest for LLM apps，适合 RAG、Agent、回归测试 |
| `TruLens` (3.5k stars) | LLM 应用评测与 tracing | 适合观察 RAG/Agent 中间链路和组件级质量 |
| `Phoenix` (10.8k stars) | LLM observability 与 eval | 适合 trace、dataset、experiment、retrieval/response eval |
| `promptfoo` (23.8k stars) | Prompt / RAG / Agent 测试与红队 | 配置简单，适合 CI/CD、模型对比、安全测试 |
| `OpenAI Evals` (19.1k stars) | 自定义 LLM 应用评测 | 适合把业务样本整理成 eval，做回归测试和模型对比 |
| `garak` (8.6k stars) | LLM 漏洞扫描 | 偏安全红队，覆盖 hallucination、data leakage、prompt injection、toxicity 等 |
| `Giskard` (5.7k stars) | LLM/ML 测试 | 适合安全、偏见、幻觉、RAG 等自动化测试 |
| `LLMPerf` (1.1k stars) | 推理性能压测 | 测 inter-token latency、generation throughput 等 |
| `AIPerf` (482 stars) | 生成式 AI 性能 benchmark | 面向 OpenAI-compatible 或常见推理服务做吞吐、延迟评测 |

## 选型建议

如果只是做一个基础模型横评，可以先用：

```text
OpenCompass (7.2k stars) / lm-evaluation-harness (13.5k stars) / LightEval (2.5k stars)
```

如果是评测 RAG 应用，可以先用：

```text
Ragas (15k stars) + DeepEval (17.3k stars) + Phoenix (10.8k stars) / TruLens (3.5k stars)
```

如果是评测 Agent，可以先用：

```text
DeepEval (17.3k stars) + promptfoo (23.8k stars) + Phoenix (10.8k stars) / TruLens (3.5k stars)
```

如果是上线前安全检查，可以先用：

```text
garak (8.6k stars) + promptfoo (23.8k stars) + Giskard (5.7k stars)
```

如果是推理服务性能压测，可以先用：

```text
LLMPerf (1.1k stars) / AIPerf (482 stars) / vLLM Benchmark CLI (87.7k stars)
```
